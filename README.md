One line under 200 characters: the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM. The wallet was bought to stop a sleepy human from draining its owner — and at 3 AM, that sleepy human is the owner, holding it. Pure Python standard library, fully deterministic: the same line, byte for byte, on every run.

## Run it

```sh
python3 main.py
```

It writes the excuse to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set).
